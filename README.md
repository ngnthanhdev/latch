Latch is a menu-bar app for macOS that watches your long-running tasks —
Claude Code, Codex, Node, Docker, Python and more — and keeps the Mac awake
exactly as long as they're busy. When the work finishes, Latch lets the
machine sleep again. No more "caffeinate forever" and no more dead builds
because the lid closed.

## Features

- ☕ **Task-aware wake lock** — detects real activity (CPU/disk) of the tools
  you choose, releases automatically when they go idle
- ⚡ **One-click manual hold** — 30 minutes to 8 hours, or until you cancel
- 💻 **Closed-lid mode (Pro)** — keep tasks running with the lid shut, with a
  root-helper watchdog so sleep is never stuck disabled
- 🌡 **Live CPU die temperature & fan** readouts in the menu bar panel
- 🔌 **Charger-only guard** — never drains the battery by accident
- 🔄 **Auto-updates** via Sparkle; signed & notarized by Apple

## Requirements

- macOS 13+ (Apple Silicon)

## Install

Download [Latch.dmg](https://latchmac.com/download/Latch.dmg), open it and
drag **Latch** into *Applications*. The app is Developer-ID signed and
notarized by Apple.
